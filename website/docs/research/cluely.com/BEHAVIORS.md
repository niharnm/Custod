# Cluely.com — Behaviors

## Scroll-driven
- Header floating CTA appears when `#download-button` scrolls out of viewport
- Section dividers scaleX 0→1 on enter viewport (spring)
- Section headings/stats fade up on enter viewport
- Meeting notes card springs up on scroll

## Click-driven
- FAQ accordion (single open)
- Mobile nav drawer
- Undetectability compare slider (mouse drag)
- Window grid card (click to highlight cell)

## Time-driven
- Hero H1 word stagger springs
- Hero demo container spring entrance
- Dock icon stagger
- Listen card recording timer + waveform RAF animation
- Bottom CTA Cmd/Return key toggle every 7s when in view

## Hover
- Purple buttons scale 1.03 hover / 0.97 active
- App Store button scale 1.02 hover
- Nav links color brighten

## Responsive
- Mobile horizontal snap scroll for undetectability cards
- Mobile hamburger menu replaces desktop nav
- Meeting notes stack on mobile, layered on desktop
